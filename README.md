# Music Downloader App

A starter Android app for downloading and listening to music locally using Jetpack Compose, Retrofit, and ExoPlayer.

## Features included
- Search songs via iTunes free API
- Display song cards with artwork
- Download preview files to app storage
- Play downloaded tracks locally with ExoPlayer
- Compose-based UI with Material 3 theme

## Tech stack
- Kotlin
- Jetpack Compose
- MVVM
- Retrofit
- ExoPlayer
- Room-ready architecture skeleton

## Prerequisites
- Android Studio Ladybug or newer
- JDK 17+
- Android SDK 34

## Setup
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the app on an emulator or device.

## Notes
This project is intentionally a starter scaffold for a music downloader app. You can extend it with:
- real API authentication
- full song downloads
- playlists and favorites
- database persistence
- background download service
